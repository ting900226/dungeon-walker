# 地城行者

手機直式、自動戰鬥的像素風地城遊戲。單一檔案，用瀏覽器打開就能玩。

**遊玩網址：** https://ting900226.github.io/dungeon-walker/

## 玩法

角色會在隨機生成的地城裡自己往前走、遇到怪物就單挑，走到盡頭打 Boss。你只要看，並在畫面下方整備裝備：

- 打怪、開寶箱會掉裝備，詞綴會真的改變技能（多射、爆炸、連鎖閃電…）
- 🎲 重鑄詞綴，賭一把
- 死路房有寶箱（可能是寶箱怪）、祭壇、治療泉
- 每 2 關換一個主題：石牢、幽暗墓地、熔岩洞

進度存在你的瀏覽器裡。
